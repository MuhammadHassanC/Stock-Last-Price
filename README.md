# 📈 Stock Price Viewer

A simple Python script to fetch and display the **latest market price** of any stock using the [yfinance](https://pypi.org/project/yfinance/) library.

---

## 🚀 Features
- Get the latest stock price instantly.
- Uses Yahoo Finance data.
- Lightweight and easy to use.

---

## 🛠️ Requirements
- Python 3.7+
- [yfinance](https://pypi.org/project/yfinance/)

Install requirements:
```bash
pip install yfinance


git clone https://github.com/Shifrozy/Stock-Last-Price.git
cd Stock-Last-Price


python stock_price.py
